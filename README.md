# Lambda Web Functions Express

## ローカルで動かす方法

1. DynamoDBテーブルを準備
1. ソースをDL
1. npm install
1. ソースにDDBテーブルを記述
1. npm run start

### 1. DynamoDBテーブルを準備

パーティションキーを `id` として「テーブルの作成」

### 2. ソースをDL

Download ZIP

### 3. インストール

```
npm install
```

### 4. ソースにDDBテーブルを記述

- src/index.js

16行目付近

```js
const tableName = "";
```

### 5. npm run dev

```
npm run dev
```

## デプロイ方法

### 1. 関数名を指定してデプロイ

```
aws lambda-web deploy \
  --name 関数名 \
  --code . \
  --entry-point src/index.js
```

### 2. 関数のIAMロールにポリシー追加

IAMで関数名を元にロールを探し下記ポリシーをインラインで作成

```json
{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Effect": "Allow",
			"Action": [
				"dynamodb:PutItem",
				"dynamodb:Scan"
			],
			"Resource": "arn:aws:dynamodb:ap-northeast-1:アカウントID:table/テーブル名"
		}
	]
}
```

## 関数のアップデート方法

デプロイと同じコマンドを実行

```
aws lambda-web deploy \
  --name 関数名 \
  --code . \
  --entry-point src/index.js
```

## ポイント

- 謎の `index.js` がデプロイされる

`entory-point`を指定すると自動でが作られる以下の記述のファイルでエントリーポイントを実行するもの

```js
// Auto-generated by 'aws lambda-web deploy'. Loads your entry point.
const entryPoint = "./src/index.js";
import(entryPoint).catch((err) => {
  console.error(`Failed to load entry point ${entryPoint}:`, err);
  process.exit(1);
});

```
